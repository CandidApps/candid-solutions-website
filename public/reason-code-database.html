VISA

Visa Chargeback Reason Codes

Visa reason codes follow a two-digit category prefix (10 = Fraud, 11 = Authorization, 12 = Processing Errors, 13 = Consumer Disputes) followed by a period and a specific number. The merchant response window is typically 30 days from notification.

Fraud 10.x — Fraud
Authorization 11.x — Authorization
Processing 12.x — Processing Errors
Disputes 13.x — Consumer Disputes
MASTERCARD

Mastercard Reason Codes

Mastercard uses four-digit codes beginning with 48. The merchant response window is generally 45 days from the chargeback date.

Fraud Fraud
Authorization Authorization
Processing Point of Interaction Errors
Disputes Cardholder Disputes
AMEX

American Express Reason Codes

American Express codes use a letter prefix (A = Authorization, C = Cardmember Dispute, F = Fraud, P = Processing Errors). Amex acts as both issuer and network — there is no neutral arbitration.

Authorization A — Authorization
Disputes C — Cardmember Disputes
Fraud F — Fraud
Processing P — Processing Errors
DISCOVER

Discover Reason Codes

Discover codes are mostly two-letter codes, with fraud codes using a UA prefix. Discover operates as both issuer and network — there is no external arbitration. The merchant response window is typically 20 days.

Fraud UA — Fraud / Unauthorized
Authorization Authorization
Processing Processing Errors
